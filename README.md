 🌿 LifeCare

LifeCare is a health and wellness management system designed to help users organize and track different aspects of their daily health and well-being in one place.

The project provides a simple console-based system where users can create an account, manage their personal information, track their habits, manage medicines and appointments, and generate health reports.

---

 ✨ Features

 👤 User Management
- Register a new account
- Login and logout
- View profile
- Edit personal information
- Delete account

💧 Water Tracker
- Add consumed water cups
- View today's water intake
- View water consumption history

 😴 Sleep Tracker
- Add daily sleep information
- View today's sleep
- View sleep history

 😊 Mood Tracker
- Add daily mood
- View today's mood
- Edit mood by date
- Delete mood by date
- View mood by date
- Track mood streak

 🏃 Activity Tracker
- Add daily activities
- View today's activities
- Edit activities
- Delete activities
- View activities by date
- Track activity streak

 💊 Medicine Management
- Add medicines
- View medicines
- Search for medicines
- View medicine details
- Edit medicines
- Delete medicines
- Mark doses as taken
- View today's doses
- Medicine notifications and reminders

 📅 Appointment Management
- Add appointments
- View appointments
- Search appointments
- View appointment details
- Edit appointments
- Delete appointments
- Update appointment status
- View today's appointments


### 📊 Reports
- Daily reports
- Weekly reports
- Monthly reports

### 📈 Dashboard
- Display a summary of the user's health and wellness information
